Add a Diamond tool. Press `D` and drag to place a diamond (rhombus) element; it supports the shared fill, stroke and opacity styles, `Shift`/`Alt` sizing modifiers, arrow bindings, centered text labels, copy/paste and transforms. Exposes `DiamondElement`, `createDiamond` and `createDiamondTool`.

The Draw tool shortcut moved from `D` to `P` so Diamond can use `D`.
