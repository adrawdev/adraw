## Installation

```bash
pnpm add @adraw/core

# npm
npm install @adraw/core
```

## Overview

`@adraw/core` provides the `AdrawCanvas` class, which manages all drawing state and renders to an SVG element inside a given container. It can also run headless (without a DOM) for server-side or test environments.

## Quick start

```ts
import { AdrawCanvas } from "@adraw/core"

const canvas = new AdrawCanvas({ container: document.getElementById("app")! })
```

Pass `container` to mount immediately, or omit it and call `canvas.mount(el)` later.

## Initial content

Load a saved document or a small element array at construction time:

```ts
const canvas = new AdrawCanvas({
  container,
  initialElements: [rectangle],
  // …or restore a serialized document. This takes precedence over
  // initialElements.
  initialDocument: savedDocument,
})
```

Initial content is cloned, has its arrow bindings resolved, and becomes the
history baseline — the first undo returns to this state instead of an empty
canvas. Adapters expose the same options through their provider/service.

## Tools

| Tool        | Description                               |
| ----------- | ----------------------------------------- |
| `select`    | Select, move, resize, and rotate elements |
| `hand`      | Pan the viewport                          |
| `draw`      | Freehand path drawing                     |
| `eraser`    | Erase elements by painting over them      |
| `rectangle` | Draw rectangles                           |
| `ellipse`   | Draw ellipses                             |
| `line`      | Draw lines                                |
| `arrow`     | Draw arrows                               |
| `text`      | Add free text or shape labels             |
| `note`      | Place a sticky note and edit its text     |

```ts
canvas.setActiveTool("draw")
canvas.getActiveTool() // "draw"
```

While drawing a `rectangle` or `ellipse`, hold `Shift` to constrain it to a
square/circle, or `Alt` to size it outward from the center point.

### Tool styles

Configure per-tool styles at construction, or change them at runtime with
`setToolOptions`. Changes also restyle matching elements in the current
selection. Use `setStyle` to merge the same styles into every tool at once;
fields a tool does not support are ignored for that tool. `getStyle` reads the
effective style for the current context: the selected elements first, then the
active tool, then the global style.

```ts
const canvas = new AdrawCanvas({
  container,
  tools: {
    draw: { smoothing: 0.7, strokeWidth: 4 },
    rectangle: {
      cornerRadius: 8,
      fillColor: "#ffd43b",
      opacity: 0.35,
      strokeWidth: 3,
    },
    text: {
      fontFamily: "monospace",
      fontSize: 24,
      lineHeight: 1.4,
      strokeColor: "#111",
      textAlign: "center",
    },
    note: {
      fillColor: "#fde68a",
      fontSize: 22,
      textAlign: "center",
    },
  },
})

canvas.setToolOptions("draw", { strokeWidth: 6 })
canvas.setToolOptions("text", { fontSize: 32, textAlign: "left" })

canvas.getToolOptions("rectangle")
// { fillColor: "#ffd43b", opacity: 0.35, strokeColor, strokeWidth: 3, cornerRadius: 8 }

canvas.setStyle({ opacity: 0.5, strokeColor: "#f00", strokeWidth: 3 })

// Selected elements win, then the active tool, then global defaults.
canvas.selectAll()
canvas.getStyle()
```

Configurable tools are `draw`, `rectangle`, `ellipse`, `line`, `arrow`, `text`
and `note`. Shared options are `strokeColor`, `strokeWidth` and `opacity`;
`fillColor` applies to `rectangle`, `ellipse` and `note` (combine it with
`opacity < 1` for translucent highlights). The tool-specific ones are
`smoothing` (draw), `cornerRadius` (rectangle), and `fontSize`, `fontFamily`,
`textAlign`, `lineHeight` and `autoSize` (text). Notes add `padding`, `width`
and `height` sizing options. `setStyle` merges a partial style across every
tool, applying each field only to the tools that support it; `getStyle` returns
the style of the selection (or its common fields), the active tool, or the
global style. `setStrokeColor` remains a shortcut for the global stroke color
and clears per-tool color overrides.

Subscribe to `toolOptionsChange` to keep a custom toolbar in sync:

```ts
canvas.on("toolOptionsChange", ({ tool, options }) => {
  console.log(tool, options)
})
```

## Elements

Each element on the canvas has a type:

- `rectangle` — rounded or sharp-cornered rect
- `ellipse` — oval / circle
- `path` — freehand stroke (Catmull-Rom smoothing)
- `line` — line
- `arrow` — two-ended connector with optional bindings
- `text` — label, free or bound to a shape/arrow
- `note` — sticky note with wrapping text and a folded corner
- `media` — raster image
- `group` — container for other elements

Rectangles and ellipses accept `fillColor`; every element accepts `opacity`
(`0`–`1`). A translucent highlighter background is just a rectangle with
`fillColor: "#ffd43b"` and `opacity: 0.35`. Freehand paths are stroked only.

## Text

Text elements support `fontSize`, `fontFamily`, `textAlign`, `lineHeight` and
`autoSize`. With `autoSize: true` (the default) the box grows with each line and
only `\n` breaks lines; with `autoSize: false` the text wraps at the element's
`width` and the box grows vertically. Dragging the left or right resize handle
switches a text element to fixed width; dragging a corner scales its font size.

Editing happens inline: double-click a text element (or press `Enter`/`F2` with
it selected) to edit it, `Enter` inserts a newline, and `Escape` or
`Ctrl`/`Cmd+Enter` commits. Starting an edit switches the active tool to
`select` (the text tool's drag-to-create gesture still finishes as select), and
the element is cleared from the selection while the editor is open so no resize
handles compete with the caret; the text (or its shape, for a label) is selected
again when editing ends. While mounted, `AdrawCanvas` measures text with the
2D canvas API so boxes match the rendered glyphs. Pass `measureText` to
`AdrawCanvas` to supply your own measurer (for example to use loaded web fonts).

```ts
const canvas = new AdrawCanvas({
  container,
  measureText: (text, options) => measureTextLayout(text, options),
})
```

### Sticky notes

The `note` tool (`N`) places a sticky note: click to create a default-sized note
(200×200) centered on the pointer, or drag to size it. The note opens its inline
editor immediately, so you can start typing. Double-click a note (or press
`Enter`/`F2` while it is selected) to edit it later. Text is centered and
vertically aligned inside the note, wraps at the padded content width, and the
note grows taller when the text no longer fits. Notes have a soft drop shadow;
`strokeColor` is the note's ink and `fillColor` is its background.

```ts
canvas.setActiveTool("note")
canvas.setToolOptions("note", { fillColor: "#bbf7d0", fontSize: 24 })
```

### Labels inside shapes and arrows

Double-clicking a rectangle, ellipse or arrow — or clicking near a shape's
center with the text tool — creates a centered label. Labels are regular text
elements with a `containerId`, so they are measured, styled and serialized like
any other text. A shape label wraps at the shape's inner width but its box
shrinks to the longest wrapped line, so the editor grows and shrinks
horizontally until it reaches that width, and grows vertically as lines are
added. An arrow label sits on the line and follows `labelPosition` (`0`–`1`,
default `0.5`), and the arrow shaft is split around the label so the line never
crosses the text. Labels move, rotate and resize with their container, are
copied and pasted with it, and are deleted when it is.

While a labeled shape is selected, text styles can still be applied to its
label with `setToolOptions("text", { ... })`. The text tool's click has three
outcomes: edit the text under the pointer, add/edit a shape label, or create
free text. Dragging horizontally with the text tool creates a fixed-width text
instead of a click-sized one.

```ts
canvas.setToolOptions("text", { fontSize: 18, textAlign: "center" })

const label = [...canvas.getElements().values()].find(
  (element) => element.type === "text" && element.containerId === rectId,
)
// { containerId: rectId, textAlign: "center", labelPosition: null, ... }
```

## Viewport

```ts
const canvas = new AdrawCanvas({
  container,
  viewport: {
    minZoom: 0.25,
    maxZoom: 8,
    zoomSensitivity: 0.001,
    fitPadding: 32,
    constrainToContent: true,
  },
})

canvas.zoomIn()
canvas.zoomOut()
canvas.resetZoom()
canvas.zoomToFit()
canvas.zoomToFit({ padding: 64 })
canvas.zoomToFit({ bounds: { x: 0, y: 0, width: 1920, height: 1080 } })
canvas.setViewport({ x: 0, y: 0, zoom: 1.5 })
canvas.getViewport() // ViewportState
```

`zoomToFit()` accepts bounds as either `x`/`y`/`width`/`height` or
`left`/`right`/`top`/`bottom`; without `bounds` it fits every visible element.
Its padding defaults to `viewport.fitPadding` (32px). When bounds are passed,
`constrainToContent` uses them as the content region until the next fit.

With `constrainToContent: true`, panning is clamped so content stays in view
(content is centered when it fits) and zooming out stops at the zoom of the
last `zoomToFit()`. Call `zoomToFit()` once content is loaded to establish that
floor.

Mouse wheel zooms when `Ctrl`/`Cmd` is held; otherwise pans. Pinch-to-zoom works on touch devices.

## History

```ts
canvas.canUndo() // boolean
canvas.canRedo() // boolean
canvas.undo()
canvas.redo()
canvas.pushHistory() // record an explicit checkpoint
canvas.clearHistory() // current state becomes the new baseline
```

Keyboard shortcuts are scoped to the canvas by default: the SVG is focusable and
takes focus on pointer down, so shortcuts never leak into forms, dialogs or
other widgets on the page. `Ctrl+Z` / `Ctrl+Shift+Z` (or `Ctrl+Y`) undo and redo
while the canvas has focus.

```ts
new AdrawCanvas({ container, keyboard: "canvas" }) // default: only while focused
new AdrawCanvas({ container, keyboard: "document" }) // anywhere on the page
new AdrawCanvas({ container, keyboard: "none" }) // call canvas.handleKeyDown yourself
```

Programmatic inserts can skip history with `{ history: false }`:

```ts
canvas.insertMedia(image, { history: false })
canvas.addElement(element, { history: false })
canvas.loadDocument(doc, { history: false })
canvas.setElements(elements, { history: false })
```

`withoutHistory(fn)` suppresses every checkpoint pushed inside the callback, which is useful for multi-step initialization:

```ts
canvas.withoutHistory(() => {
  canvas.loadDocument(doc)
  canvas.insertMedia(image)
})
```

Changes made outside history are folded into existing checkpoints, so a later
undo keeps them instead of restoring a state that predates them. After loading
or initializing a document, call `clearHistory()` if you want the current state
to become the undo baseline and discard everything before it.

## Selection

```ts
canvas.selectAll() // select every element
canvas.clearSelection() // deselect all
canvas.deleteSelected() // remove selected elements
canvas.getSelectedIds() // Set<ElementId>
```

Hold `Shift` while dragging a resize handle to preserve the selection's
original proportions.

## Z-order

Elements render in ascending `zIndex` — higher values sit on top. Newly drawn
elements and inserted media stack above everything by default.

```ts
canvas.bringToFront([id]) // above everything, preserving relative order
canvas.sendToBack([id]) // below everything
canvas.setZIndex(id, 10) // exact value
```

Group elements carry their children, and all three methods accept
`{ history: false }`. To place a base image underneath existing annotations,
restack it after insertion:

```ts
const [image] = canvas.insertMedia(baseImage)
canvas.sendToBack(image.id)
```

`insertMedia` also accepts an explicit base index with `{ zIndex }`; existing
elements keep their indexes, so it does not reflow the stack on its own.

## Clipboard

```ts
canvas.copy() // snapshot the selection (group children included)
canvas.cut() // copy, then delete the selection
canvas.paste() // paste clones centered on the pointer
canvas.paste({ x: 120, y: 80 }) // …or on an explicit canvas point
```

`Ctrl/Cmd+C`, `Ctrl/Cmd+X`, and `Ctrl/Cmd+V` map to the same operations.
Pasted elements get new IDs (group references are remapped), are selected, and
the paste is a single undo step. Without a pointer position, paste falls back to
the viewport center.

The clipboard is an in-memory buffer per canvas. Use
`serializeClipboard()` / `deserializeClipboard(text)` to bridge it to the system
clipboard, or pass custom hooks:

```ts
const canvas = new AdrawCanvas({
  container: el,
  clipboard: {
    serialize: (elements) => JSON.stringify(elements),
    deserialize: (data) => JSON.parse(data),
  },
})

await navigator.clipboard.writeText(canvas.serializeClipboard()!)
canvas.deserializeClipboard(await navigator.clipboard.readText())
canvas.paste()
```

## Events

```ts
canvas.on("change", ({ elements }) => {
  /* elements changed */
})
canvas.on("viewportChange", ({ viewport }) => {
  /* viewport moved/zoomed */
})
canvas.on("toolChange", ({ tool }) => {
  /* active tool switched */
})
canvas.on("selectionChange", ({ selectedIds }) => {
  /* selection changed */
})

canvas.off("change", handler)
```

## Snapping

Elements snap to other elements' edges and centers while moving, resizing or
drawing; alignment guides are shown while snapped.

```ts
const canvas = new AdrawCanvas({
  container: el,
  snapping: { threshold: 8 },
  // Snap without holding a modifier. When false/omitted, snapping only
  // activates while Ctrl (or Cmd) is held during the gesture.
  isSnapMode: false,
})

// update at runtime
canvas.setSnappingConfig({ threshold: 12 })
canvas.setIsSnapMode(true)
canvas.getSnappingConfig()
canvas.getIsSnapMode()
```

## Headless usage

Create an instance without a container for pure state management:

```ts
const canvas = new AdrawCanvas()
canvas.handlePointerDown(x, y, event)
canvas.handlePointerMove(x, y, event)
canvas.handlePointerUp(x, y, event)
// mount later
canvas.mount(document.getElementById("app")!)
```

## Cleanup

```ts
canvas.destroy()
```

Disconnects the resize observer, removes the SVG element, and unsubscribes all
DOM and engine event listeners. Safe to call before mounting or more than once.
