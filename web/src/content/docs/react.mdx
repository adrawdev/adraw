## Installation

```bash
pnpm add @adraw/react

# npm
npm install @adraw/react
```

React 17 or later is required as a peer dependency.

## Quick start

Wrap your app (or the part that needs the canvas) with `CanvasProvider`, then render the `Canvas` component wherever you want the drawing surface.

```tsx
import { Canvas, CanvasProvider, useTool } from "@adraw/react"

function Toolbar() {
  const { tool, setTool } = useTool()
  return (
    <div>
      <button
        onClick={() => setTool("select")}
        aria-pressed={tool === "select"}
      >
        Select
      </button>
      <button onClick={() => setTool("draw")} aria-pressed={tool === "draw"}>
        Draw
      </button>
      <button
        onClick={() => setTool("rectangle")}
        aria-pressed={tool === "rectangle"}
      >
        Rectangle
      </button>
    </div>
  )
}

export default function App() {
  return (
    <CanvasProvider>
      <Toolbar />
      <Canvas style={{ flex: 1 }} />
    </CanvasProvider>
  )
}
```

## Components

### `<CanvasProvider>`

Context provider that creates and owns the canvas engine. All hooks and `<Canvas>` must be rendered inside it.

```tsx
<CanvasProvider
  options={{
    initialElements: savedElements,
    snapping: { threshold: 8 },
    viewport: {
      constrainToContent: true,
      fitPadding: 64,
      maxZoom: 8,
      minZoom: 0.25,
    },
    tools: {
      draw: { strokeWidth: 4, smoothing: 0.7 },
      rectangle: { cornerRadius: 8 },
      text: { fontSize: 24 },
    },
  }}
  onReady={(engine) => engine.setActiveTool("draw")}
>
  {children}
</CanvasProvider>
```

| Prop      | Type                            | Description                                                   |
| --------- | ------------------------------- | ------------------------------------------------------------- |
| `options` | `CanvasReactOptions`            | Snapping / viewport / per-tool styles and initial document    |
| `onReady` | `(engine: AdrawCanvas) => void` | Called once per engine after `<Canvas>` mounts and subscribes |

The core options include initial content:

| Option            | Type              | Description                                                                 |
| ----------------- | ----------------- | --------------------------------------------------------------------------- |
| `initialElements` | `CanvasElement[]` | Elements loaded before the first render. Ignored after the provider mounts. |
| `initialDocument` | `CanvasDocument`  | Serialized document to restore. Takes precedence over `initialElements`.    |

The engine is created **headless** during the first provider render and only
mounted into the DOM by `<Canvas>`. It is therefore available to descendants
immediately, without depending on effect order. In React StrictMode the effect
cycle still runs twice, but the engine instance and its document survive and
`onReady` fires once.

#### `setOptions`

`setOptions` applies live changes without recreating the engine:

- `tools` and `hideOverlayWhileTransforming` update the current engine.
- `keyboard`, `snapping`, `viewport` config, `isSnapMode` and clipboard hooks are
  constructor-only. Changing them recreates the engine while preserving the
  document, viewport and current per-tool styles (undo history and selection are
  reset).
- Replacing `options` with a new object that has equal values is a no-op, so
  inline options objects no longer wipe the canvas.

### `<Canvas>`

Mounts the drawing surface. Fills its parent container (`width: 100%; height: 100%`).

```tsx
<Canvas className="my-canvas" style={{ borderRadius: 8 }} />
```

| Prop        | Type                  | Description   |
| ----------- | --------------------- | ------------- |
| `className` | `string`              | CSS class     |
| `style`     | `React.CSSProperties` | Inline styles |

## Hooks

All hooks must be called inside `<CanvasProvider>`.

### `useCanvas()`

Returns the raw context value, including `elements`, `viewport`, `activeTool`, `selectedIds`, and the underlying `AdrawCanvas` instance (`engine`). `vanillaRef` is still available for backwards compatibility, but new code should use `useCanvasEngine()`.

### `useCanvasEngine()`

Returns the engine and a reactive readiness flag:

```tsx
const { engine, isReady } = useCanvasEngine()

useEffect(() => {
  if (!isReady) return
  // DOM-dependent setup, e.g. engine.toImage()
}, [engine, isReady])
```

`engine` is non-null from the first render, so effects do not depend on the
child/parent effect order. `isReady` becomes `true` after `<Canvas>` has mounted
the engine and the provider has subscribed to its events; the state change
triggers a re-render. Use the engine directly for core-only APIs such as the
clipboard (`copy()`, `cut()`, `paste()`).

### `useTool()`

```ts
const { tool, setTool } = useTool()
// tool: ToolType — "select" | "hand" | "draw" | "eraser" | "rectangle" | "ellipse" | "line"
setTool("draw")
```

### `useViewport()`

```ts
const { viewport, setViewport, zoomIn, zoomOut, resetZoom, zoomToFit } =
  useViewport()
// viewport: ViewportState — { x: number, y: number, zoom: number }
zoomToFit({ padding: 64 })
zoomToFit({ bounds: { x: 0, y: 0, width: 1920, height: 1080 } })
```

### `useHistory()`

```ts
const { undo, redo, canUndo, canRedo } = useHistory()
```

### `useSelection()`

```ts
const { selectedIds, elements, selectAll, clearSelection, deleteSelected } =
  useSelection()
```

### `useToolOptions()`

Returns resolved style options for every configurable tool plus a setter:

```ts
const { toolOptions, setToolOptions } = useToolOptions()
// toolOptions.rectangle.cornerRadius, toolOptions.draw.smoothing, ...
setToolOptions("rectangle", { cornerRadius: 12 })
```

### `useStyle()`

Convenience hook for one tool's style. Pass the tool explicitly, or omit it to
follow a homogeneous selection and fall back to the active tool:

```tsx
const { style, setStyle, tool } = useStyle()
// or: const { style, setStyle } = useStyle("rectangle")

if (style && tool) {
  return (
    <input
      type="range"
      value={style.strokeWidth}
      onChange={(event) =>
        setStyle({ strokeWidth: Number(event.target.value) })
      }
    />
  )
}
```

All tools share `strokeColor`, `strokeWidth` and `opacity`; `fillColor` applies
to `rectangle` and `ellipse` (combine it with `opacity < 1` for translucent
highlights). Tool-specific fields are available when the inferred tool matches:
`cornerRadius` (rectangle), `fontSize` (text), `smoothing` (draw). Changing a
style restyles matching elements in the current selection, so the same control
works for the selected shape and the next one.

### `useTransformOverlay()`

```ts
const { hideWhileTransforming, setHideWhileTransforming } =
  useTransformOverlay()
// hideWhileTransforming: boolean — whether the selection bounding box +
// resize/rotation handles are hidden while a resize/rotation gesture is in
// progress (defaults to true; set via the hideOverlayWhileTransforming option)
setHideWhileTransforming(false)
```

## Server components (Next.js)

All exports are marked `"use client"`. Import them only from client components or use a dynamic import with `ssr: false`.
