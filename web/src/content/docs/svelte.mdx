## Installation

```bash
pnpm add @adraw/svelte

# npm
npm install @adraw/svelte
```

Svelte 5 or later is required as a peer dependency.

## Quick start

Wrap the part of your app that needs the canvas with `CanvasProvider`, then render `Canvas` wherever you want the drawing surface.

```svelte
<script lang="ts">
  import { Canvas, CanvasProvider, useTool } from "@adraw/svelte"
  import Toolbar from "./Toolbar.svelte"
</script>

<CanvasProvider>
  <Toolbar />
  <Canvas style="flex: 1;" />
</CanvasProvider>
```

```svelte
<!-- Toolbar.svelte -->
<script lang="ts">
  import { useTool } from "@adraw/svelte"

  const tool = useTool()
</script>

<button onclick={() => tool.setTool("select")} aria-pressed={tool.tool === "select"}>
  Select
</button>
<button onclick={() => tool.setTool("draw")} aria-pressed={tool.tool === "draw"}>
  Draw
</button>
```

## Components

### `<CanvasProvider>`

Sets up an isolated canvas context (via Svelte's context API) for its children.

```svelte
<CanvasProvider
  options={{
    initialElements: savedElements,
    snapping: { threshold: 8 },
    tools: { draw: { strokeWidth: 4 }, rectangle: { cornerRadius: 8 } },
  }}
  onReady={(engine) => engine.setActiveTool("draw")}
>
  {@render children()}
</CanvasProvider>
```

| Prop      | Type                            | Description                                                |
| --------- | ------------------------------- | ---------------------------------------------------------- |
| `options` | `CanvasSvelteOptions`           | Snapping / viewport / per-tool styles and initial document |
| `onReady` | `(engine: AdrawCanvas) => void` | Called once after `<Canvas>` mounts the engine             |

`options` accepts `initialElements` / `initialDocument` (`initialDocument`
wins). The engine is created headlessly, so components can use it during setup.
Options are read when the provider is created; changing the prop later does not
recreate the engine, preserving in-progress content.

### `<Canvas>`

Mounts the drawing surface. Fills its parent container (`width: 100%; height: 100%`).

```svelte
<Canvas class="my-canvas" style="border-radius: 8px;" />
```

| Prop    | Type     | Description   |
| ------- | -------- | ------------- |
| `class` | `string` | CSS class     |
| `style` | `string` | Inline styles |

## Composables

### `useCanvas()`

Returns the raw context value: `state` (reactive `elements`, `viewport`, `activeTool`, `selectedIds`), `isReady`, and `instance` — a `{ current: AdrawCanvas }` ref populated as soon as the provider is created. The instance carries core-only APIs too, such as the clipboard (`copy()`, `cut()`, `paste()`).

### `useCanvasEngine()`

Returns `{ engine, isReady }`:

```ts
const { engine, isReady } = useCanvasEngine()
// engine: AdrawCanvas — available before <Canvas> mounts
// isReady: boolean getter — true after mount
```

### `useTool()`

```ts
const tool = useTool()
// tool.tool: ToolType — "select" | "hand" | "draw" | "eraser" | "rectangle" | "ellipse" | "line"
tool.setTool("draw")
```

### `useViewport()`

```ts
const viewport = useViewport()
viewport.viewport // ViewportState — { x: number, y: number, zoom: number }
viewport.zoomIn()
viewport.zoomOut()
viewport.resetZoom()
viewport.zoomToFit()
viewport.zoomToFit({ padding: 64 })
viewport.zoomToFit({ bounds: { x: 0, y: 0, width: 1920, height: 1080 } })
```

### `useHistory()`

```ts
const history = useHistory()
history.undo()
history.redo()
history.canUndo()
history.canRedo()
```

### `useSelection()`

```ts
const selection = useSelection()
// selection.selectedIds, selection.elements
selection.selectAll()
selection.clearSelection()
selection.deleteSelected()
```

### `useToolOptions()`

```ts
const { toolOptions, setToolOptions } = useToolOptions()
// toolOptions: getter — resolved styles for every configurable tool
setToolOptions("rectangle", { cornerRadius: 12 })
```

### `useStyle(tool?)`

Reactive getters for one tool. Omit `tool` to infer it from a homogeneous
selection (or the active tool):

```svelte
<script lang="ts">
  import { useStyle } from "@adraw/svelte"

  const styles = useStyle()
  // or: const styles = useStyle("rectangle")
</script>

{#if styles.style}
  <input
    type="range"
    value={styles.style.strokeWidth}
    oninput={(event) =>
      styles.setStyle({ strokeWidth: Number(event.currentTarget.value) })}
  />
{/if}
```

All tools share `strokeColor`, `strokeWidth` and `opacity`; `fillColor` applies
to `rectangle` and `ellipse` (combine it with `opacity < 1` for translucent
highlights). Tool-specific fields: `cornerRadius` (rectangle), `fontSize`,
`fontFamily`, `textAlign`, `lineHeight` and `autoSize` (text), `smoothing`
(draw). Changes also restyle matching selected elements.

### `useTransformOverlay()`

```ts
const overlay = useTransformOverlay()
// overlay.hideWhileTransforming: boolean — whether the selection bounding box +
// resize/rotation handles are hidden while a resize/rotation gesture is in
// progress (defaults to true; set via the hideOverlayWhileTransforming option)
overlay.setHideWhileTransforming(false)
```
